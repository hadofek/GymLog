## Key Design Patterns

- **Bento cards:** `#1D1F27` background, `1px` border at `#434654`, `border-radius: 16px`, padding `24px`
- **Active/glow state:** outer border glow using primary blue at 20% opacity
- **Label style:** ALL CAPS, Space Grotesk, 12px, 0.1em letter-spacing, `#8D90A0` color
- **Stat numbers:** Lexend 800, monument sizing, left-aligned
- **Progress bars:** flat ends (not rounded caps), track `#1F1F27`, colored fill matching workout type
- **Status dots:** small circle + 5px Gaussian blur glow (green = active, red = recording)
- **Calendar:** colored dot BELOW the date number (not a filled circle behind it)
- **Workout type colors:** Weighted = `#608BFF`, Cardio = `#4AE176`, Bodyweight = `#608BFF`, Flexibility = `#FFB690`
